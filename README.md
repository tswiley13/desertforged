# Desert Iron Technologies

Website for Desert Iron Technologies, an independent Arizona software company building custom web and mobile apps. Live at [desertirontech.com](https://desertirontech.com).

Built with React and Vite. All site content (copy, products, services, FAQ) lives in `src/data.js`.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`. The custom domain is set in `public/CNAME`.
